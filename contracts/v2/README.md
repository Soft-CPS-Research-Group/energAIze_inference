# Explicit draft boundary evolution

These files extend the separately versioned documents exposed under `/admin/v1`:

- `preparation.schema.json`: isolated local bundle preparation from iteration 3.
- `configuration.schema.json`: installation/bundle/bindings plus the v2 safety policy.
- `safety-policy.schema.json`: scalar precision and explicit aggregate curtailment.
- `evaluation.schema.json`: original proposal, final evaluated actions and safety audit.

The last three schemas are generated by `scripts/export_safety_schemas.py` from
`app/contracts/v2/safety.py`. Existing v1 schemas and documents remain supported
without silent migration. See [safety correction](../../docs/safety-correction.md)
for supported capabilities, mode semantics, fallback and a reproducible example.
A schema-valid configuration still needs preparation; evaluation is not activation
or physical command delivery.
